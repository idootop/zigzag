常见问题

打开提示「已损坏，无法打开。你应该将它移到废纸篓」怎么办？

不是真的坏了。这个应用没有向苹果交费做认证，所以 macOS 会先拦一下。

打开「终端」，粘贴下面这行按回车，之后正常双击即可：xattr -dr com.apple.quarantine /Applications/ZigZag.app

会动我的原文件吗？

不会。压好的放进一个新文件夹，原来的一个都不碰。不满意就把新文件夹删掉，等于什么都没发生过。

拍摄时间、地点这些信息会丢吗？

不会。什么时候拍的、在哪拍的、用什么拍的，压完保持不变，不会丢失。

压到一半关掉，进度会丢吗？

不会。关掉、重启、断电都行，下次打开会停在上次的地方，点「接着跑」就继续，压好的不用重来。

支持 Intel 芯片的 Mac、Windows 或 Linux 吗？

暂时不支持，目前只做 Apple 芯片的 Mac（M1 及以后）。

收费吗？

不收费，没有内购，也不用注册账号。代码全部公开在 GitHub 上。
